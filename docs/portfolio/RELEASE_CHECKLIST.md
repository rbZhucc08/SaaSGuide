## 真正公开前必须再检查

1. 重新运行 `run_checks.ps1`；
2. 检查 `git status` 和准备推送的提交；
3. 扫描当前文件和完整 Git 历史中的密钥、个人信息和真实公司数据；
4. 确认 README 截图和实际页面一致；
5. 确认所有相对链接在 GitHub 可打开；
6. 用一台干净 Windows 环境按 README 从零安装；
7. 在私有仓库先观察 GitHub Actions 结果；
8. 用户本人完成一次 4–6 分钟演示；
9. 再决定是否公开仓库和创建 Release。
