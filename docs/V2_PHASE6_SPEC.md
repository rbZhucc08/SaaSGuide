# V2 Phase 6 报告与数据洞察规格

## 目标

由 Python 从固定数据计算风险、误报、逾期和处理时间指标，页面展示趋势和行动；CSV 与 XLSX 可下载。报告文字只复述已计算数字。

## 固定答案

- 6 条候选风险、3 条高风险、3 条已确认、2 条误报。
- 误报率 33.3%。
- 截至 2026-09-07 有 2 条逾期行动。
- 已关闭记录平均处理时间 23.8 小时。

## 导出要求

- CSV 使用 UTF-8 BOM，便于中文 Excel 打开。
- XLSX 包含周报摘要、风险明细、行动明细三张表和原生趋势图。
- 表格值、图表来源和页面指标必须来自同一固定样本。
