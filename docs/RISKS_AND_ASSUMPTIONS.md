# 风险与假设

## 当前假设

- 输入是单个 `.xlsx`，只有一个可见工作表，第一行是列名，最多 1000 条数据行。
- 项目任务在一个文件内只属于同一项目；依赖只引用本文件内任务。
- 中文和英文常见列名别名能覆盖模拟样本，但不能覆盖所有企业模板。
- 用户在确认前会核对自动列映射；系统不把自动建议当成事实。

## 已知风险与成本

| 风险 | 影响 | 当前控制 | 尚未解决的成本 |
|---|---|---|---|
| 企业模板差异 | 别名建议或解析失败 | 可修改映射、明确错误 | 需要更多经授权样本和回归集 |
| Excel 公式或复杂格式 | 读到计算式或错误值 | 发现公式即停止；限制一个可见工作表 | 合并单元格、旧 `.xls` 和复杂模板未支持 |
| 重复导入 | 产生重复项目版本 | 保留 SHA-256；相同来源哈希被拦截 | 跨版本差异与合并尚未实现 |
| 本地原始数据含敏感信息 | 公开仓库泄露 | `data/raw/`、`data/normalized/`、运行目录被 Git 忽略 | 尚无账号、权限、脱敏、保留和删除策略 |
| 浏览器证据不完整 | 高估兼容性 | 分开记录自动测试、内置样本、用户手动文件选择 | Edge 和其他系统未验证 |
| JSON 并发写入 | 文件冲突或覆盖 | 当前仅单人本地 Demo | 数据库、事务和多人协作留到后续阶段 |
| 规则误报或漏报 | 后续风险结论不可靠 | V2-P1 不运行风险规则 | V2-P2 必须建立标准答案和人工反馈 |

## 明确排除

本阶段不处理真实客户数据、外部 SaaS 写回、模型读取上传文件、自动指派负责人、修改截止日期、关闭风险或发送通知。任何扩展都必须重新评估隐私、授权、错误恢复和验证成本。
