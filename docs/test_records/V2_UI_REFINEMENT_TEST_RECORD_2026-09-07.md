- 概览：强化真实指标、最近活动和下一步的层级；没有增加样板数据。

- 知识库：突出版本、确定性摘录、引用和拒答语义。
- 行动跟踪：强化人工确认区、行动状态和完成信号。

- 输入实验室：把已实现、仅检测和未配置状态分开显示。
- 手机导航：`shell.js` 只在不超过 700px 时将当前导航项滚入可见区，不调用 API、不改变业务状态。
