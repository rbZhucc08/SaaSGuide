# SaaSGuide V2 业务差异化公司数据验收记录

验收日期：2026-09-08。

## 结论

上一版共享项目和任务模板的占位数据已经替换。新版数据按行业分别定义业务背景、经营特征、项目流程、任务名称、状态分布、制度和风险标准。模拟数据集不再计入首页指标。

这仍是虚构数据和本地 AI 应用评测准备，不是 DeepSeek 训练数据、真实企业数据或业务效果证据。

## 数据差异

- 6 家公司：企业 SaaS、跨境电商、智能制造、物流仓储、营销服务、医疗信息化。
- 30 个项目名称全部不同，180 个任务名称全部不同，48 个公司制度版本。
- 跨境电商覆盖海外仓补货、Ozon 商品卡合规、Amazon 广告、高退货 SKU 和多平台库存同步。
- 制造覆盖预测性维护、替代材料认证、批次追溯、MES 接口和产能平衡。
- 其他行业分别覆盖租户与续费、仓配 SLA、素材与归因、医疗隐私与院内接口等场景。
- 状态分布覆盖健康、阻塞、延期、临期、混合风险和信息不足，不再让所有公司共享同一状态链。

## 公司标准

每家公司包含：`operating_characteristics`、`high_overdue_days`、`due_soon_days`、`blocked_hours_high`、`review_cadence`、`escalation_role` 和 `mandatory_evidence`。

- 相同逾期两天的任务，在 SaaS 三天高风险阈值下为中风险，在制造一天阈值下为高风险。
- 逾期阈值和临期窗口已进入 Python 确定性扫描。
- 完整公司画像与风险标准通过 `company_context` 进入 DeepSeek 请求；模型仍只能使用当前公司允许的制度引用。
