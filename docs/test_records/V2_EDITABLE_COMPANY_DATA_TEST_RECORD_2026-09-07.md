# SaaSGuide V2 可编辑模拟公司数据验收记录

验收日期：2026-09-07。

## 结论

产品运行数据已从固定样板切换为可编辑本地公司数据。固定风险、知识和报告文件继续保留作隔离评测夹具，但知识问答、Orchestrator、公司项目扫描、行动列表和周报不再直接以这些夹具作为产品结果。

这不是训练或微调 DeepSeek。本轮实现的是可编辑数据、确定性检索、受控 Agent 上下文和本地持久化。

## 数据与功能

- Seed：虚构公司“星云数科（模拟）”、6 个部门、5 个项目、25 条任务、16 个制度/历史案例版本。
- 运行副本：`generated/company-data.json`；首次访问初始化一次，清空后不会因重启自动恢复。
- 项目：新增、逐字段编辑、任务行增删、删除、显式恢复。
- 制度：新增、编辑、删除、版本和状态校验。
- 风险：可从公司项目选择器扫描当前项目；固定夹具收进“开发评测”。
- 知识问答与 Agent：读取当前运行制度；空知识库时本地 ASK，不调用模型编造引用。
- 行动：移除 GET/POST 自动 `seed_demo`；页面不再预填固定行动。
- 报告：从当前风险决策 JSONL 与 SQLite 行动计算；CSV/XLSX 均动态生成；无记录时显示 0 和真实空状态。

旧固定样本导入、风险决策、文本核对和自动 Seed SQLite 记录已从产品路径移出或清空。原文件备份位于 `generated/backups/legacy-fixed-runtime-20260907/` 和 `generated/backups/saasguide-demo.pre-editable-data-20260907.db`；`generated/` 不进入 Git。

## 限制

- 全部公司、制度、项目和人员均为模拟数据，不证明真实企业采用或业务效果。
- 未验证多人并发、生产部署、权限体系或真实企业数据迁移。
- 固定评测指标只能描述隔离夹具，不能外推真实准确率。
