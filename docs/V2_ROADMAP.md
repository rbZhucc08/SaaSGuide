# SaaSGuide V2 路线图

本路线图只描述顺序和闸门，不代表后续功能已经实现。

| 阶段 | 目标 | 当前状态 | 进入下一阶段的闸门 |
|---|---|---|---|
| V2-P0 | 保护 V1 基线 | 已完成 | 38 项回归、Chrome 最小验收、本地基线提交 |
| V2-P1 | XLSX 到统一项目 JSON | 已完成并验收 | 正常与故障样本、人工确认、落盘、53 项总测试、浏览器记录 |
| V2-P2 | 确定性风险扫描 | 已完成并验收 | 可解释规则、证据、去重、人工决策、固定评测集 |
| V2-P3 | TXT/Markdown/DOCX 事实接入 | 已完成并验收确定性底座 | 原文片段、候选、ASK、人工核对；真实模型提取未验证 |
| V2-P4 | 知识库与 RAG | 已完成离线检索底座 | 版本引用、拒答、冲突和固定引用评测；向量/LLM 未验证 |
| V2-P5 | SQLite 与行动跟踪 | 已完成并验收 | 迁移、关联、人工确认、行动状态和事件审计 |

| V2-P7 | 语音、PDF/OCR、更多适配器 | 已完成安全底座验收 | 普通 PDF、OCR 检测、WAV 元数据、模拟适配器；真实服务未验证 |
| V2-P8 | 部署与作品集收尾 | 本地发布已完成并验收 | 本地启动、密钥边界、限制、错误记录、作品集文档；公开部署未执行 |
| 发布后产品化修订 | 产品入口与输入方式纠偏 | 已完成并验收 | 根页只读真实本地状态、`/v2` 退役、映射可自由输入、独立 HR 演示文档 |
| AI 编排纠偏 | 恢复 V2 真实模型能力并约束证据链 | 已完成并验收 | 单 Orchestrator、五个领域 Skill 合约、真实 ASK/PLAN、引用白名单、Python 校验、107 项测试 |
| 多公司差异化与规则基准 | 让公司背景、项目、制度和规则结果可比较 | 已完成并验收 | 6 公司、30 项目、180 任务、跨公司 TP/FP/FN 与 132 项测试 |
| 私有作品集发布包 | 面向外部读者整理仓库 | 已完成本地验收 | README、PRD、流程图、使用说明、案例、证据、安全、MIT、CI 配置与 135 项测试；尚未推送 |

## 当前停止线

V2-P0 至 P8、本地模拟数据、AI 编排、跨公司规则基准和私有作品集发布包已经按各自范围验收。公开仓库、真实 GitHub Actions、公开部署、P3 真实模型抽取、向量 RAG、P6 模型周报叙述、OCR、语音和外部连接器仍有独立验收闸门，不能因本地发布包完成而视为完成。
