# V3 阶段 10：GitHub 作品集发布规格

## 目标

把当前分支整理成可审计、可从零安装的私有 GitHub 候选版本。外部仓库创建、推送、在线 Actions、Release 和公开部署必须由项目所有者授权并参与。

## 本地实施

- 更新 README、`.env.example` 和发布清单至 V3 当前状态；
- 扫描当前 Git 跟踪文件和所有可达历史文本 blob，不回显匹配值；
- 在新的虚拟环境按锁定依赖安装并运行完整检查；如外部包索引不可用，保存失败原因并保持未完成状态；
- 保存历史扫描、干净环境检查和页面截图证据；
- 保留模拟数据、本地运行、真实 API 和外部验证边界。

## 外部完成条件

- 项目所有者明确仓库归属、私有/公开范围和安全联系方式；
- 创建私有 GitHub 仓库并推送；
- GitHub Actions 四项 Windows/Linux、Python 3.11/3.12 作业实际通过；
- 创建 tag 和 GitHub Release；
- 用户本人检查演示视频，并决定是否只保留本地演示。

在这些条件完成前，状态只能写“本地发布候选完成，GitHub 发布待授权”，不能称已发布。
