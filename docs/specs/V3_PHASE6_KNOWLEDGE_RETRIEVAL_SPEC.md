# V3 阶段 6：知识检索与文档理解规格

日期：2026-09-09

## 现状判断

模拟 Seed 已有 6 个公司上下文、共 48 个制度版本；单次公司上下文为 8 个版本。规模还不需要外部向量数据库，但版本选择、精确引用、可疑指令隔离和后续扩展需要统一检索接口。

## 目标

- 按中文二元词和英文词进行关键词匹配；
- 使用本地稀疏词频向量余弦分数补充排序；
- 按句子边界分块并保留原文字符位置；
- 支持文档、状态、公司、类型和标签元数据筛选；
- 同一文档优先生效版本；
- 多个生效版本冲突时拒答；
- 排除含提示词注入特征的片段并报告安全提示；
- 页面展示检索版本、方法、分块编号和精确位置。

## 非目标

- 本阶段的“向量”是本地稀疏词频向量，不是语义 Embedding 或向量数据库；
- 不调用 DeepSeek 生成知识答案；
- 不实现扫描 PDF 的 OCR、图片表格识别或语音转写；
- 不把 DOCX 表格行提取扩展为任意复杂表格理解；
- 不声称固定问题集代表真实企业问答质量。

## 检索流程

```text
当前公司制度版本
→ 句子边界分块与原文位置
→ 元数据过滤
→ 可疑指令片段排除
→ 关键词分数 + 本地稀疏向量余弦分数
→ 生效版本选择与重排
→ 版本冲突检查
→ 精确引用或拒答
```

检索版本为 `hybrid-retrieval-v1`。综合分数为关键词覆盖 65% 加稀疏向量余弦 35%。阈值仍为 0.18，属于本地固定规则，需要通过独立外部数据再校准。

## 安全边界

文档中的“忽略系统规则”“system prompt”等文字只作为不可信内容。命中的片段不进入答案或模型上下文，并返回 `prompt_injection_text_excluded`。这是一组有限模式，不等于完整的提示词注入防护。

## 完成闸门

- 分块、精确位置、混合分数、元数据过滤、生效版本、冲突拒答和可疑指令排除有测试；
- 既有 10 个固定知识问题继续通过；
- 页面能展示检索方法和引用位置；
- 浏览器完成回答和拒答验收，控制台无错误。
