# V3 阶段 8：安全、权限与数据治理规格

## 目标

在接触真实数据前建立可检查的阻断条件，并补足本地 Demo 能够诚实实现的输入防护、敏感信息提示、写接口限流、密钥扫描和威胁模型。

## 本阶段实现

- 只读安全就绪接口和数据源页状态卡；
- 文本证据与 XLSX 预览的常见敏感信息样式检测，只返回类别和数量；
- DOCX/XLSX 的文件边界和压缩展开边界；
- 单进程、单来源写接口限流；
- Git 跟踪文件启发式密钥扫描，纳入完整检查；
- 威胁模型与数据治理边界。

## 明确不声称完成

当前没有身份认证、RBAC、真正租户隔离、数据库加密、托管密钥服务或恶意软件扫描。`company_id` 只是本地上下文。因此接口状态必须保持 `blocked_for_real_data`，只允许模拟或已去标识化测试数据，也不得公开部署。

## 验收

- 自动测试覆盖敏感信息检测、不回显、压缩边界、限流和就绪状态；
- 完整检查执行跟踪文件密钥扫描；
- 应用内 Chromium 显示阻断状态、已实现控制和缺失控制；
- 测试记录分别列出实现、未实现和外部依赖。
