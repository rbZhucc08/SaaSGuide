# V3 阶段 1：信息架构与仓库整理规格

## 目标

让第一次进入仓库的人从 README 直接理解产品、体验路径、AI 边界和证据入口，同时保留 V1/V2 历史事实。

## 实施范围

- 把根目录的 V1 阶段记录和旧交接材料归档到 `docs/history/`；
- 重写 README 第一屏，增加三分钟体验、V1 到 V3 的变化和文件地图；
- 更新仍指向旧根目录位置的当前文档；
- 增加 Markdown 本地链接检查，并纳入 `run_checks.ps1`；
- 保留当前运行文件、核心源码、安全说明、变更记录和 V3 交接入口。

## 非目标

- 不删除或改写旧验收记录中的历史数字；
- 不改变 API、页面、数据、AI 调用或数据库；
- 不处理阶段 2 的视觉设计。

## 验收标准

- README 能分别引导 HR、产品和技术读者；
- V1/V2/V3 的关系和当前限制清楚；
- Markdown 本地文件链接检查通过；
- 完整自动检查和浏览器入口验收通过；
- Git diff 无空白错误。
