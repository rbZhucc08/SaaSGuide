# V3 阶段 2：高完成度 UI 与演示体验规格

## 目标

让八个主要页面在默认状态就能看出同一条“规则证据—AI 草稿—人工确认—行动报告”主线，并产生肉眼可见的构图变化。

## 设计方向

- 应用壳从深色紫色侧栏改为浅色工作区导航，活动页使用深海军蓝强调；
- 页面标题区改为深色信息 Hero，集中呈现页面任务、边界和主要操作；
- 首页默认展示六步业务主线；
- 数据源默认展示四步受控导入；
- 风险雷达默认展示规则、证据、AI 和双人工闸门的关系；
- 其余页面复用相同标题、内容层级、状态和响应式规则。

## 保护边界

- 不改路由、API、关键 DOM ID、请求字段或数据库；
- 不改变 XLSX 自由映射、ASK/PLAN、引用白名单、行动数量和人工确认；
- 不新增 Agent、向量 RAG、OCR、语音识别或外部连接器；
- 不把模拟数据和固定评测写成真实业务结果。

## 验收标准

- 八个路由在桌面与 390 × 844 检查；
- 无页面级横向溢出，主要操作在视口内，活动导航可见；
- 页面控制台无 warning/error；
- 核心扫描、AI 草稿与人工确认回归不被破坏；
- 保存阶段 2 前后对照截图。
