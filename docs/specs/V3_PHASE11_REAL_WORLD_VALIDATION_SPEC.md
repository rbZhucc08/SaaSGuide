# V3 阶段 11：真实业务验证规格

## 子场景

限定为“项目负责人审查延期风险，并决定是否接受、修改或拒绝系统建议”。不在本阶段验证整个平台，也不推断商业收益。

## 本地实施

- 提供研究协议、访谈与试用任务、基线及结果记录模板；
- 提供只接受授权、去标识化结构化证据的分析器；
- 统计参与人数、建议处置分布和任务耗时的描述性差异；
- 页面明确显示外部证据是否缺失或无效；
- 原始访谈记录、身份、公司名和联系方式不得进入 Git。

## 真实完成条件

- 至少一位符合目标角色的真实参与者明确同意参与；
- 使用已获授权且去标识化的数据；
- 在使用系统前记录相同任务的当前流程基线；
- 记录每条建议被接受、修改或拒绝及编码原因；
- 对局限、反例和拒绝原因进行复盘。

即使收集到小样本，本阶段也只能称为“取得试点观察证据”，不能据此声称普遍有效、提高效率或产生商业价值。
