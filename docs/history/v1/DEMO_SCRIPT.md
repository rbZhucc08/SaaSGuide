# 3 分钟演示脚本

## 0:00–0:30 项目定位

“这是一个个人学习 Demo，场景是虚构项目管理 SaaS。它帮助项目人员集中查看风险，并用 DeepSeek 辅助整理处理建议。这里全部是模拟数据，没有真实客户或生产部署。”

## 0:30–1:00 风险看板

展示四张概览卡、风险等级筛选和详情。说明所有数量来自当前风险列表，不是写死的数字。

## 1:00–2:10 新建风险闭环

1. 点击“新建风险”。
2. 填写标题、事实描述、影响、责任人和截止日期。
3. 点击“AI 分析新风险”。
4. 解释 ASK 表示信息不足，PLAN 表示模型给出了结构完整的建议。
5. 指出建议等级和行动并不会自动保存。
6. 点击“确认加入风险列表”，展示列表和统计变化。
7. 刷新页面，证明新风险保存在本地 JSON。

## 2:10–2:35 安全与验证

“密钥只在服务器环境变量中。模型返回要经过程序校验；写入前备份旧数据。38 项自动测试覆盖正确流程、错误格式、API 失败和保存失败。”

## 2:35–3:00 边界与下一步

“当前选择 JSON 是为了快速证明完整闭环，因此只适合单人本地演示。它没有登录、多用户、数据库或生产部署。若继续产品化，下一步才是账号权限、数据库、审计历史和并发处理。”
