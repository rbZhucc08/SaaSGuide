# 访谈与试用任务

## 试用任务

给参与者一份经授权且去标识化的项目任务表，要求：识别一个可能延期的风险，核对支持证据，判断风险是否成立，审查 AI 的 ASK 或 PLAN，并决定是否保存后续行动。

基线任务与系统任务必须使用相近的任务量和风险复杂度。若使用同一材料，记录可能存在的学习效应。

## 访谈提纲

1. 你平时如何发现并跟踪这类延期风险？
2. 哪一步最耗时间，最容易遗漏什么？
3. 你是否能看出风险结论来自哪条任务事实和哪份制度？
4. 哪条建议可以直接采用？为什么？
5. 哪条建议需要修改或应被拒绝？缺少了什么上下文？
6. 人工确认风险和人工确认行动这两个步骤是否清楚？
7. 哪些信息你不愿上传或不愿授权系统读取？
8. 如果下周再用一次，什么条件会促使或阻止你使用？

不要诱导参与者说“提高效率”，也不要只记录正面反馈。追问具体行为、反例和拒绝原因。
