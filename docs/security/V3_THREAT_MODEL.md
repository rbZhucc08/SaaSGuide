# SaaSGuide V3 本地 Demo 威胁模型

## 范围与资产

保护对象包括用户导入文件、统一 JSON、SQLite 行动记录、模型密钥、模型运行记录和备份。当前信任边界是单台设备上的 `127.0.0.1` 服务；浏览器、上传文件、知识文档和模型输出都按不可信输入处理。

## 主要威胁与当前控制

| 威胁 | 当前控制 | 剩余风险 |
|---|---|---|
| 文件过大或压缩炸弹 | 格式、原始大小、行列数、压缩条目及展开大小限制 | 没有恶意软件扫描 |
| 上传内容含个人信息或密钥 | 预览阶段检测常见样式，只回传类别和数量 | 规则覆盖有限，可能漏检 |
| 文档提示词注入 | 可疑指令标记为内容，不能覆盖程序规则 | 新型表达可能漏检 |
| 模型伪造引用或越权写入 | 引用白名单、结构校验、双人工闸门 | 模型建议仍可能不准确 |
| 高频写请求耗尽本地资源 | 单进程、单来源滑动窗口限流 | 重启后清零，不适合公网或多实例 |
| 密钥进入仓库 | 环境变量、Git 忽略、跟踪文件启发式扫描 | 尚未扫描完整 Git 历史 |
| 本地数据被其他设备用户读取 | 运行产物不入 Git | SQLite 和文件未加密，没有操作系统级权限验证 |
| 跨公司误读 | 服务端保持当前公司上下文测试 | 没有身份、租户和授权边界，不能称租户隔离 |

## 真实数据与公网阻断条件

在身份认证、角色权限、真正租户隔离、数据库加密、托管密钥、恶意软件扫描和可审计保留策略完成前，真实公司或个人数据不得进入系统，服务不得公开部署。安全就绪接口以此返回 `blocked_for_real_data`。

## 删除、备份和恢复

页面提供带确认的公司删除、当前公司清空和模拟数据恢复。SQLite 迁移前会备份并有恢复测试。当前没有自动保留期限执行器；设备所有者仍需管理 `generated/`、`data/raw/`、`data/normalized/` 和备份目录。
