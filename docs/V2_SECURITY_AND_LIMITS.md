# SaaSGuide V2 安全与限制

## 已实现

- 服务默认绑定 `127.0.0.1`。
- XLSX 与文本类输入分别限制 2 MB；Flask 总请求限制 3 MB；PDF 固定接口的解析器限制 5 MB。
- 扩展名白名单、编码与结构错误返回明确代码。
- 响应包含 CSP、nosniff、DENY frame、no-referrer、权限策略和 no-store。
- 4xx/5xx 只记录时间、方法、路径和状态，不记录请求正文、密钥或上传内容。
- `.env`、运行数据、导入数据和备份被 Git 忽略。

## 未实现

- 身份认证、授权、租户隔离、数据库加密、恶意文件扫描、病毒查杀、速率限制、TLS、备份恢复和合规删除。
- 因此只能用于本地模拟演示，不能接收真实客户或商业敏感资料。
