# SaaSGuide V2 发布后产品化变更记录

## 变更结论

2026-09-05 将产品功能、阶段验收和求职演示三种内容重新分层。当前产品根入口只显示 V2 工作流的本地真实状态；旧 `/v2` 演示总览和 V1 固定五条风险不再作为产品页面；数据源映射允许输入任意原始列名。

## 具体变更

1. 删除 `/v2` 与 `v2-overview.html`、`v2-overview.css`。HR 演示路径改由 `SaaSGuide_V2_HR_演示引导.docx` 承载。
2. `/` 沿用 V1 的深色侧栏、指标卡、主列表和右侧详情结构，但内容改为 V2 数据源、人工审计、证据核对、行动和下一步。
3. `/api/dashboard` 只读取 `data/normalized/*.json`、人工审计 JSONL、已存在的 SQLite 行动表和知识文档，不读取 `risk-data.json`，也不会为了显示数字自动播种样本。
4. 映射控件由 `select` 改为 `input type=text` 与 `datalist`。用户可以输入不在建议中的文字；服务端重新校验时会明确返回 `mapping_unknown_column`。

## 历史保留

P0-P8 规格和测试记录描述各阶段当时实际发生的结果，不修改。旧页面和固定样板可从 Git 历史追溯；当前状态以本记录、最新代码与发布后验收记录为准。

## 真实性边界

这仍是个人学习 Demo，数据来自模拟样本或用户主动导入的本地文件。自动测试和固定评测不能证明真实企业准确率、用户采用、风险降低或商业价值。

## 功能页视觉统一补充

2026-09-05 继续统一七个左侧导航功能页：新增 `v2-shell.css` 作为共享产品外壳，统一侧栏、导航、画布、卡片、按钮、表单、状态消息和响应式规则。七页都显示完整八项导航及当前页状态。

页面中删除了 `V2-Pn`、`STEP n`、阶段说明和面向验收的长篇话术；保留与操作直接相关的文件限制、模拟样本标识、人工确认要求、来源提示和未配置能力状态。页面专属 CSS 只负责各功能区域布局。
