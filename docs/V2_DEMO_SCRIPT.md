# SaaSGuide V2 演示脚本

1. 运行 `start_v2.ps1`，打开 `/v2`，先说明个人学习 Demo 和模拟数据边界。
2. 在数据源页加载有效 XLSX，查看字段映射、校验、预览和人工确认。
3. 在风险雷达扫描固定样本，解释规则证据、去重和 83.33% 查准率/查全率。
4. 在文本证据页加载 DOCX，指出 3 条事实、2 条待确认和 1 条默认驳回的提示词注入文本。
5. 在知识库问“高风险需要多久升级”，展示 v2.0 引用和旧版冲突；再问真实营收，展示拒答。
6. 在行动页演示未勾选时被拦截，人工确认后创建并更新状态。
7. 在报告页核对固定指标并说明 CSV/XLSX 与页面同源。
8. 在输入实验室展示普通 PDF 已解析，同时指出 OCR、语音和真实连接器尚未验证。

全程不要声称真实客户、真实企业接入、生产效果、公开部署或真实多模态服务。
