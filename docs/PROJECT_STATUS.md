## 人工验证与自动化边界

- 用户在 Chrome 中手动确认：`valid_project_tasks_cn.xlsx` 与 `invalid_dates.xlsx` 都可通过本地文件控件选择，并可触发“生成预览”。
- 浏览器自动化无法设置该本地文件控件，因此没有自动复现真实文件选择动作。
- 文件上传端点及其解析结果由自动集成测试覆盖；页面错误与成功结果由相同 XLSX 内容的内置样本路径完成浏览器核验。
- 以上证据组合不等于真实企业文件兼容性，也不等于生产环境上传测试。
