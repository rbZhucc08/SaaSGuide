## 当前业务链路

```text
项目数据与文本证据
→ 字段和来源校验
→ 确定性规则生成候选风险
→ 当前生效制度检索
→ DeepSeek ASK / PLAN 草稿
→ Python 结构与引用校验
→ 人工确认风险
→ 人工确认行动
→ SQLite 事件审计
→ CSV / XLSX 报告
```

候选风险不是事实，PLAN 不是正式行动。风险确认和行动确认是两个独立人工闸门。

## 当前证据

- 固定规则基准：TP=119、FP=4、FN=18、Precision=96.75%、Recall=86.86%；
- 该结果来自作者构造和标注的合成回归集，不是企业准确率或模型准确率；
- 历史真实 DeepSeek 浏览器证据包括两次递进 ASK 和一次合法 PLAN；
- V3 阶段 5 没有重新取得真实网络调用，模型失败路径主要由模拟合约测试覆盖；
- 飞书链路已用作者自建演示数据在真实租户验证：读取 5 条、日期归一化、5 条风险候选、人工闸门、独立行动表写回、幂等及源表未修改；
- 上述飞书验收不代表生产可用，批量、并发、配额、更多字段类型和多租户仍未验证；
- 阶段 11 的真实参与者为 0，当前只有验证工具和研究方案。

## 仍需外部条件

- 两位独立标注者完成盲标；
- 如继续向生产方向推进，需要另行验证飞书批量、并发、配额、字段类型、权限收敛和多租户隔离；
- 真实目标角色参与小规模试用并明确同意；
- 用户本人录制演示，并在公开前决定是否接受或重写历史审计中的两项人工复核内容；
- 是否公开和是否提供公网 Demo 仍需单独决定。

## 明确限制

- 没有登录、RBAC、真正租户隔离、数据库加密或生产部署；
- 没有 Embedding 模型或向量数据库；本地“向量”是稀疏词频表示；
- 没有 LangChain、LangGraph、OpenAI Agents SDK 或多 Agent；
- 没有真实 OCR、语音识别、真实客户、商业收益或企业采用证据；
- 当前只能称为“本地可运行的项目风险 AI 应用个人项目”。

历史阶段事实保存在 `docs/test_records/` 和 `docs/history/`。旧记录中的测试数量与页面状态只代表当时结果。
