# V2 Phase 5 SQLite 与行动跟踪规格

## 目标

用 SQLite 支持项目、来源、文档、候选风险、证据、人工决策、行动、报告、反馈、AI 运行和错误日志的关联与审计。第一版只做单机单用户，不做多租户。

## 权限边界

- 创建行动必须收到显式 `human_confirmed=true`。
- 保存负责人角色，不把模拟角色映射为真实人员。
- 状态只允许 open -> in_progress/cancelled，in_progress -> completed/open/cancelled。
- 每次创建和转换追加事件，不覆盖历史。

## 验收

- 迁移幂等，外键启用，所需实体表存在。
- 未人工确认的行动被拒绝。
- 创建、进行中、完成三步产生完整事件链。
- 固定日期下正确标记逾期行动。
