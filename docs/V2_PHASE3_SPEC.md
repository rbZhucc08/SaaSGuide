# V2 Phase 3 文本和 DOCX 证据接入规格

## 目标

把 TXT、Markdown 和 DOCX 中的原文转换为带来源位置的候选事实。候选只能在人工接受、修改或驳回后写入证据审计，不能自动修改任务或正式风险。

## 固定输入与标准答案

- 输入：`data/documents/phase3_project_weekly_update.docx`，虚构项目周报。
- 明确任务事实：3 条，分别关联 T-002、T-003、T-004。
- 待确认信息：2 条。
- 提示词注入文本：1 条，必须保留为普通引文并默认驳回。
- 模型状态：固定样本验收不调用模型；不能把确定性解析写成真实 AI 提取。

## 验收条件

- 支持 UTF-8、UTF-8 BOM、GBK 文本和 DOCX 段落/表格读取。
- 保存文件名、SHA-256、片段位置和原文。
- 不支持格式、空文件、超 2 MB 文件给出明确错误。
- 页面支持固定样本、文件上传预览和逐条人工选择。
- 人工记录明确声明仅写证据审计，不写回任务或风险。
- 自动测试、Chrome 桌面和 390 x 844 页面、控制台检查均留证。
