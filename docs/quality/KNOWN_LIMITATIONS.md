# 已知限制

## 产品范围

- 这是本地单用户 Demo，没有登录、角色权限、多人协作或通知；
- `company_id` 只用于本地上下文切换，不是生产多租户；
- 没有真实客户、企业采用记录或业务收益；
- 首页数字只代表当前本地确认记录。

## 数据

- 公司、项目、任务和制度都是模拟内容；
- 模拟数据可以验证固定条件下的流程，不能替代真实业务分布；
- 用户上传兼容性只覆盖当前样本和已测试格式；
- 项目有启发式敏感样式提示和 Office 压缩边界，但没有恶意软件扫描、完整 DLP 或合规删除机制；
- 不应输入真实商业敏感资料。

## 风险规则

- 当前规则只覆盖逾期、临期低进度、阻塞和直接依赖；
- 不理解复杂业务语义；
- 不遍历完整依赖链；
- 没有使用剩余工时修正临期风险；
- 固定评测与场景同源，存在偏差。

## 知识检索

- 当前是关键词与本地稀疏词频向量混合检索，不是 Embedding 模型或向量数据库 RAG；
- 文档量较小时可解释，但不适合大规模知识库；
- 无依据时会拒答；
- 文档版本正确不等于制度内容本身正确。

## DeepSeek

- 项目调用训练好的模型 API，没有训练或微调模型；
- 模型输出具有随机性；
- 结构和引用检查不能保证业务建议正确；
- 当前只有少量真实 API 验收，没有批量稳定性、延迟和实际费用评测；
- 已有限重试、错误分类与本地 Token 预算；没有队列、熔断、跨进程配额或多供应商降级；
- AI 只输出草稿，最终责任在用户。

## 文档和多模态

- 普通 PDF 只处理可提取文本层；
- 扫描件只返回 `OCR_REQUIRED`，没有真实 OCR；
- WAV 只检查元数据，没有语音识别；
- 飞书多维表格连接器已在真实租户完成端到端验收：读同步、日期归一化、人工确认闸门与写回独立行动表；
- 飞书侧仍未验证：批量写入上限、并发写入、配额与限流表现，以及"人员"、含时间日期、公式等其他字段类型；
- 不读取飞书聊天消息，也不向客户原表写回。

## 部署与安全

- Flask 开发服务器只监听本机；
- 没有生产 WSGI、TLS、域名、CDN、备份恢复和监控；
- 没有账号认证、数据库加密、生产审计权限和负载测试；
- 代码已推送到私有 GitHub 仓库，GitHub Actions 曾在 Windows/Linux × Python 3.11/3.12 四项矩阵通过；这不等于每个后续提交或长期运行都稳定；
- 当前没有公开在线 Demo。

## 真实业务验证

- 已有研究协议、访谈任务、去标识化证据校验和描述性分析工具；
- 当前真实参与者为 0，没有用户采用、建议效果或商业价值证据；
- 建议接受率不等于建议正确率，任务耗时差异也不能单独证明效率提升。

## 平台验证

- 主要开发和验收环境是 Windows；
- 部分浏览器记录来自 Codex 应用内 Chromium；
- 没有完成 Edge、Safari、macOS、Linux 和多人并发验证。

## 表述边界

可以称为“本地可运行的 AI 应用个人项目”或“项目风险助手 Demo”。不能称为生产级 SaaS、企业级多 Agent、真实 RAG 平台或已经产生业务效果的产品。
